# Suggested GitHub Milestones

Create these in **Issues → Milestones → New milestone**.

## M1 — Discovery Complete
**Description:** Validate the product direction, select one primary scenario and operator, define the MVP module set, and update discovery documentation.

## M2 — System Definition
**Description:** Finalize the domain model, module boundaries, event model, shared state and operational consequence logic.

## M3 — Interaction Design
**Description:** Define operator flows, information hierarchy, core interaction patterns and low-fidelity wireframes.

## M4 — Working Prototype
**Description:** Build a browser-based prototype with real state, event propagation, simulation and cross-module consequences.

## M5 — Public Demo
**Description:** Polish, deploy and document a stable public demonstration integrated with michalbiernacki.com.

## M6 — Case Study & Launch
**Description:** Package the process and outcome into a public portfolio case study, publish the repository and launch the project.
